### Наблюдение 2
- `/hello` → **200 OK**, текст: `Привет, гость!`
- `/hello/Adil` → **200 OK**, текст: `Привет, Adil!`
- `/hello/Адиль` → При стандартном фильтре `->whereAlpha('name')` возвращает **404 Not Found**, так как `whereAlpha` проверяет только ASCII-символы `[a-zA-Z]+` и не поддерживает кириллицу (Unicode).
- **Исправление:** Маршрут изменен на:
  ```php
  Route::get('/hello/{name?}', function (string $name = 'гость') {
      return "Привет, {$name}!";
  })->where('name', '[\p{L}]+');
  ```
  Знак `\p{L}` соответствует любой букве любого алфавита (Unicode Property). После исправления ответ **200 OK**, текст: `Привет, Адиль!`.

### Наблюдение 4
1. **Два запроса при отправке формы:**
   - 1-й запрос: `POST /feedback` (статус **302 Found** — редирект)
   - 2-й запрос: `GET /feedback` (статус **200 OK** — показ страницы с флеш-сообщением)
   - *Причина:* Паттерн **PRG (Post/Redirect/Get)** предотвращает повторную отправку формы при обновлении страницы браузера.
2. **Удаление `@csrf`:**
   - Приводит к ошибке **419 Page Expired** (токен CSRF отсутствует или не совпадает).
   - В исходном коде страницы директива `@csrf` разворачивается в скрытый input:  
     `<input type="hidden" name="_token" value="...">`.
3. **Отправка текста `<b>жирный</b>`:**
   - Текст выводится как текст с видимыми тегами `<b>жирный</b>` (в HTML экранируется как `&lt;b&gt;жирный&lt;/b&gt;`).
   - Конструкция Blade `{{ $variable }}` автоматически пропускает вывод через `htmlspecialchars()`, предотвращая XSS-уязвимости.

## 5. Ответы на контрольные вопросы

1. **Опишите путь запроса GET /catalog/2 в вашем приложении:**
   - `public/index.php` принимает запрос и стартует ядро приложения.
   - `bootstrap/app.php` инициализирует настройки, промежуточное ПО и маршруты.
   - `routes/web.php` находит маршрут `Route::get('/{id}', 'show')->whereNumber('id')`, проверяет, что `2` — число, и вызывает `CatalogController@show`.
   - В `CatalogController` метод `show(2)` находит запись с `id = 2` и отдает шаблон `catalog.show`.
   - `resources/views/catalog/show.blade.php` компилируется Blade, расширяя макет `resources/views/layouts/app.blade.php`.
   - Клиент получает готовый HTML со статусом `200 OK`.

2. **Почему .env не хранится в Git? Для чего нужен .env.example?**
   - `.env` содержит локальные и секретные параметры конкретной машины (ключи шифрования, учетные данные БД, пароли). Их публикация в системе контроля версий создает угрозу безопасности.
   - `.env.example` служит шаблоном для команды: в нем перечислены все необходимые ключи без конфиденциальных значений.

3. **Чем config('lab.code') отличается от env('LAB_CODE')? Что изменится после php artisan config:cache?**
   - `env()` читает напрямую из файла `.env`.
   - `config()` читает значения из древа конфигураций `config/*.php`.
   - После выполнения `php artisan config:cache` конфигурация кешируется в файл `bootstrap/cache/config.php`. При этом чтение через `env()` отключается (возвращает `null`), работает только `config()`. Любые правки в `.env` не будут иметь эффекта до сброса кеша через `php artisan config:clear`.

4. **Чем отличаются $request->query('x') и $request->input('x')?**
   - `$request->query('x')` ищет параметр только в GET-параметрах URL строки (query string).
   - `$request->input('x')` ищет параметр сначала в теле запроса (POST, JSON, FormData), а если там его нет — в GET-параметрах URL.

5. **Почему после POST-формы возвращается redirect(), а не view()?**
   - При возврате `view()` браузер остается в методе POST. Если пользователь нажмет F5, браузер повторно отправит те же данные (появится окно «Подтвердите повторную отправку формы»). Возврат `redirect()` переводит браузер в безопасный метод GET (паттерн PRG).

6. **Что такое CSRF-атака и как @csrf от неё защищает?**
   - CSRF (Cross-Site Request Forgery) — атака, при которой сторонний вредоносный сайт инициирует действие от лица авторизованного пользователя, используя его сохраненную сессию в куках.
   - Директива `@csrf` генерирует уникальный криптографический токен для формы. При отправке формы сервер проверяет совпадение токена. Вредоносный сайт не имеет доступа к токену из-за политики Same-Origin и не может подделать запрос.

7. **Что будет, если в вашем web.php убрать whereNumber('id') и открыть /catalog/abc?**
   - Запрос `/catalog/abc` совпадет с шаблоном `/{id}` и будет передан в метод `show($id)`.
   - Поскольку аргумент метода имеет типизацию `int $id`, PHP выбросит фатальную ошибку `TypeError` (статус 500) из-за несоответствия типов («Argument must be of type int, string given»), вместо корректной ошибки 404 на уровне роутера.
